# What the minified builds (bench, release) must keep although code reaches it in ways R8 cannot
# see; MinifiedOutputsCheck checks it against R8's outputs (Gradle: checkBenchMinified,
# checkReleaseMinified). One rule per line:
#   <class>                  the class survives
#   <class> <member>         its field or method survives
#   ... same-name            and keeps its own name, and its class's (code reaches it by name)
#   weak <type>              every field of the app holding a <type> (or a collection of them, or a
#                            class implementing it) survives: what it is registered with holds it
#                            only weakly
# Besides these, every native method keeps its own name and its class's: JNI binds them by name.
